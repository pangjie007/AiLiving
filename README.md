# AiLiving

娱乐型写实 AI 主播管理平台，当前交付人格/状态内核，以及带证据来源的事件、画像事实和记忆存储。

## 本机运行

需要 Node.js 26。当前里程碑无第三方依赖，无需安装包。

运行测试：`npm test`

运行演练：`npm run demo`

运行记忆存储演练：`npm run demo:memory`

## 当前能力

不可变人格发布、有限幅的状态更新和时间衰减、拒绝后的许可锁定、新同意事件去重、拒绝与人工接管后的任务取消、结束会话及跨会话凭证隔离。把可信同意事件接入正式服务时，服务端仍须验证来源与观众身份。

按工作空间、角色与观众隔离的 SQLite 事件/记忆仓库，包含来源事件去重、带证据的画像事实修订、私人记忆、仅以匿名事件为证据的公开记忆和事务化遗忘。调用仓库时 `viewerId` 必须是内部不透明 ID，不能直接传入平台账号或昵称。文件数据库可通过 `openDatabase('data/ailiving.sqlite')` 打开；内存库用于测试和演练。运行 `MemoryRepository.purgeExpired(now)` 执行保留清理：事件原文及原始来源 ID 保留 30 天，之后擦除正文并保留不含原文的证据行；常规画像事实和未固定记忆默认最多保留 90 天，固定记忆不自动过期。为确保未来的遗忘请求仍能延长拦截期，事件证据行会一直保留来源 ID 的 SHA-256 摘要，直至该事件被删除；删除后，仅保留 90 天回放拦截键。摘要不能直接解码为来源 ID，但低熵或可猜测的来源 ID 可能通过候选值比对推断出来；摘要仍可关联相同来源事件。遗忘代次墓碑用于拒绝迟到写入。清理需由后端定时任务调用，当前仓库不会自行调度。

## 当前边界

尚无管理界面、模型生成感知/画像、自动记忆巩固、节目导演、真实语音和数字人服务。规则与脚本用于机制验证，不代表真实主播智能质量。原生 TypeScript 执行尚未包含静态类型检查。
